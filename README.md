# Student Performance Analytics System

## About the Project

This project analyzes student marks and attendance using Python, NumPy and Pandas. It generates a performance report to understand individual student results and overall class performance.

## Objectives

- Calculate total and average marks for each student.
- Assign grades based on average marks.
- Identify pass and fail students.
- Compare subject-wise performance.
- Find the highest and lowest averages.
- Display the top five students.
- Identify students who need improvement.
- Demonstrate basic artificial neuron calculations using NumPy.

## Technologies Used

- Python
- NumPy
- Pandas
- VS Code

## Dataset

The project uses a CSV dataset containing 20 student records with student IDs, names, departments, subject marks and attendance.

## Features

- Student performance report
- Grade and result calculation
- Class performance summary
- Subject-wise average analysis
- Top five student ranking
- Attendance and performance analysis
- Basic neuron calculation using weights, bias and ReLU

## How to Run

1. Install Python.
2. Install the required libraries:

   pip install numpy pandas

3. Keep students.csv, functions.py and main.py in the same folder.
4. Run the program:

   python main.py

## Output

The program displays student-wise marks, averages, grades, results, class statistics, subject averages, top performers, students needing improvement and basic neuron scores.

## Learning Outcomes

This project helped me practise Python functions, loops, conditions, NumPy arrays, Pandas DataFrames and basic numerical calculations used in artificial neuron demonstrations.
